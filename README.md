# 💰 KharchBook 2.0
A lightweight, offline-first personal expense and loan manager built with HTML, CSS, and Vanilla JavaScript.

### Features
- 🏦 Multi-account tracking (Cash, Bank, UPI)
- 💳 Smart Credit Card limit & Auto-due date shifting
- 🧮 EMI installment manager
- 📅 Calendar spending view & Custom tags (#rent, #trip)
- 🔐 SHA-256 PIN Security & In-app confirmation modals
- 📱 Progressive Web App (PWA) supported
